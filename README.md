### Is XCutors free to use?

### Why does my anticomponent flag the files?

Script executors interact with external processes at runtime, which heuristic anticomponent engines often flag as suspicious. This is a false positive. Add the XCutors folder to your anticomponent exclusion list before running the tools.

### How do I update to the latest version?

Visit the repository's Releases page and download the newest ZIP archive. Replace your existing XCutors folder with the updated files, or overwrite them in place. Your saved scripts and settings will be preserved.

### Can I use my own custom Lua scripts?

Absolutely. Each executor supports loading scripts from the built-in script hub as well as pasting or importing your own custom Lua scripts directly into the editor.

### The executor is not attaching to Roblox. What should I do?

Ensure Roblox is running and you are in an active game session. Run xcutorsLoader as Administrator, confirm your anticomponent exclusion is set, and try clicking 'Inject' again. If the issue persists, restart both the executor and Roblox.

### Does this work with Roblox UWP (Microsoft Store) version?

Compatibility depends on the individual executor. Most included executors target the standard Roblox Player client. Check each executor's documentation within the package for UWP support details.

### Where can I find scripts to use?

XCutors includes a built-in script hub with popular community scripts. You can also find scripts on community forums, script-sharing websites, and Discord servers dedicated to Roblox scripting.
